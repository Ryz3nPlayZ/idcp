# V1 to V5

## V1

Goal:

- establish low-level same-machine transport primitives
- prove local communication overhead is real

Proof:

- `fabric-bench`
- `fabric-core`

## V2

Goal:

- move from transport-only thinking to memory discovery
- prove exact and near-duplicate page families are worth targeting

Proof:

- `memory-lab`
- `idcp-memory`

## V3

Goal:

- define the four engine model
- integrate flow, memory, placement, and pressure under one system story

Proof:

- `idcp-flow`
- `idcp-placement`
- `idcp-pressure`
- `idcp-bench`

## V4

Goal:

- make the system usable as a product-shaped tool
- support named workload profiles and side-by-side naive vs IDCP simulation

Proof:

- `idcp-system`
- `idcpd plan`
- `idcpd simulate`
- `idcpd bench`

## V5

Goal:

- act like an actual controllable runtime planning product
- support multiple profiles with repeatable outputs and a clear next step to replace modeled values with measured runtime values

Proof:

- profile-aware CLI
- cross-engine benchmark table
- daemon-style planner output
- tests covering engine behavior and scenario wins

## Next after V5

- replace modeled flow/copy assumptions with measured runtime traces
- add real workload snapshots
- add pressure-loop experiments under constrained memory
- move from planner to real same-host orchestrator
